# AI-assisted Large-scale Development
Type: concept
Sources: https://registerspill.thorstenball.com/p/joy-and-curiosity-79, https://lalitm.com/post/building-syntaqlite-ai/

Using AI coding tools (like Claude Code) to accomplish massive implementation work (e.g., 14,000-line PRs) that would otherwise take months, while humans focus on architecture, API design, and review. Exemplified by Matteo Collina's Node.js virtual file system PR.

## Relations
- → Code Review: "I didn't write a single line of code. I reviewed it all though and consistently nudged the AI in the right direction"
- → syntaqlite: "I believe the main reason this happened was because of AI coding agents"
- → AI-generated code: "AI turned out to be better than me at the act of writing code itself, assuming that code is obvious"
- ← Agent DX: "When you don’t have the mental thread of what’s going on, it becomes impossible to communicate meaningfully with the agent"
