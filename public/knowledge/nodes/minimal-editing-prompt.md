# minimal editing prompt
Type: strategy
Sources: https://nrehiew.github.io/blog/minimal_editing/

An explicit instruction to preserve the original code and logic as much as possible, which reduces unnecessary edits and often improves correctness.

## Relations
- → Over-Editing: "With explicit prompting, every model improves and reduces its Levenshtein Distance"
- → Reasoning models: "that same reasoning capacity also makes them better at following the constraint once it is given"
