# Ephemeral Software
Type: concept
Sources: https://registerspill.thorstenball.com/p/joy-and-curiosity-79

Software that is generated on-demand by AI agents, performs its task, and then disappears — never stored, versioned, or named. Described as software turning into a liquid that 'drips into every nook and cranny and then evaporates.'

## Relations
- → Vibe-coded Automation: "he used an agent to vibe-code a piece of software to talk to the torque wrenches via Bluetooth and record the data in the spreadsheet he uses"
- → AI-generated code: "ChatGPT writes tens or hundreds of lines of Python to resize images, create a PDF, or extract data from a CSV —and then throws it away, without anyone even having seen the code"
- ← SKILL.md files: "A file as a distillation of one's own preferences and taste and judgement and experiences, fed to a neural network trained to help you get your work done"
- ← Spec-driven development: "it also feels like you can specify what software is supposed to do without being 100% precise and, as long as the person (thing) implementing it and you have some shared understanding about what's left out of the spec, things will be fine"
