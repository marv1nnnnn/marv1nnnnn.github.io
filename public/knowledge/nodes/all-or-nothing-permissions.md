# All-or-nothing permissions
Type: concept
Sources: https://www.latent.space/p/reviews-dead

A coarse permission model where agents either get broad access or none.

## Relations
- ← Agent frameworks: "Most agent frameworks treat permissions as an all-or-nothing setting."
- ← Capability-scoped sandbox: "instead of beginning with a miniature server and then trying to constrain it, you begin with an isolate that has almost no ambient authority and then explicitly hand it the capabilities it should have"
