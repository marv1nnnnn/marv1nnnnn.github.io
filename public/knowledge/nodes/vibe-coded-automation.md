# Vibe-coded Automation
Type: concept
Sources: https://registerspill.thorstenball.com/p/joy-and-curiosity-79

Non-programmers using AI agents to create functional software solving real problems (e.g., Bluetooth torque wrench data recording), bypassing expensive specialized tools and traditional software development.
