# Unikraft
Type: technology
Sources: https://x.com/larsencc/status/2027225210412470668

Micro-VM platform providing scale-to-zero, sub-second boot, and multi-metro distribution for agent sandboxing

## Relations
- → Agent Sandbox Isolation: "Unikraft gives us scale-to-zero out of the box. When a sandbox is idle, the VM suspends. When the next request comes in, it resumes"
- ← Browser Use: "Each agent gets its own Unikraft micro-VM, booting in under a second. We provision them via Unikraft Cloud's REST API on dedicated bare metal machines in AWS"
