# RL
Type: strategy
Sources: https://nrehiew.github.io/blog/minimal_editing/

Reinforcement learning with a reward combining functional correctness and Levenshtein-based minimality; the only method reported to generalize cleanly out-of-domain without degrading broader coding ability.
