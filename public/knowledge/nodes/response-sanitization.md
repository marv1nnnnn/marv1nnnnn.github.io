# Response sanitization
Type: concept
Sources: https://justin.poehnelt.com/posts/rewrite-your-cli-for-ai-agents/

Filtering API responses before agent consumption to mitigate malicious prompt content.

## Relations
- → Google Cloud Model Armor: "`--sanitize <TEMPLATE>` pipes API responses through Google Cloud Model Armor"
- → Prompt injection: "This defends against a threat most developers haven’t considered: prompt injection embedded in the data the agent reads."
- ← Google Workspace CLI: "`--sanitize <TEMPLATE>` pipes API responses through Google Cloud Model Armor before returning them to the agent."
