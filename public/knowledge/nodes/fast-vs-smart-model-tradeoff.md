# Fast-vs-Smart Model Tradeoff
Type: concept
Sources: https://registerspill.thorstenball.com/p/joy-and-curiosity-79

The tension between using faster but less capable local models (like Qwen 35B) versus slower but smarter cloud models (like Opus 4.6). Faster models allow extra iteration cycles, but smarter models may reach correct results faster overall.

## Relations
- → AI-generated code: "With 3x faster responses, I could add an extra cycle: 'critique the plan and address the critiques.' In the time the hare was still thinking, the tortoise ran another lap"
