# WIMP model
Type: concept
Sources: https://sunilpai.dev/posts/after-wimp/

Windows, Icons, Menus, Pointer paradigm originating from Xerox PARC that organized computing around pre-authored graphical interfaces, splitting users into programmers (who issue procedures) and everyone else (who choose from menus of pre-built actions)

## Relations
- → Procedural expressibility: "the successor to WIMP is probably not "chat," at least not in the simplistic sense people sometimes mean... fixed graphical interfaces stop being the only sensible contract between user and machine once the user can increasingly express procedures through a model"
- → User-specific software: "not the end of interfaces, but the end of the assumption that interfaces must be fully fixed in advance because users cannot program the machine"
