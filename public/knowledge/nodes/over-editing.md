# Over-Editing
Type: concept
Sources: https://nrehiew.github.io/blog/minimal_editing/

A brown-field coding failure mode where a model produces functionally correct fixes but rewrites more code than necessary, making review harder and degrading code quality.

## Relations
- → Code Review: "A model that rewrites entire functions, even correctly, makes this job dramatically harder as the code is now completely unrecognizable."
- ← minimal editing prompt: "With explicit prompting, every model improves and reduces its Levenshtein Distance"
- ← minimal editing training: "A natural next question: can we train models to be more faithful editors?"
- ← Reasoning models: "Therefore, the takeaway is that the default behavior of most reasoning models is to over-edit."
