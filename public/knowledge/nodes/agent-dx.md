# Agent DX
Type: concept
Sources: https://justin.poehnelt.com/posts/rewrite-your-cli-for-ai-agents/, https://lalitm.com/post/building-syntaqlite-ai/

The quality of interaction with the coding agent, which depends on the developer maintaining a strong mental model and being able to communicate precise changes.

## Relations
- → Human DX: "Human DX optimizes for discoverability and forgiveness.

Agent DX optimizes for predictability and defense-in-depth."
- → AI-assisted Large-scale Development: "When you don’t have the mental thread of what’s going on, it becomes impossible to communicate meaningfully with the agent"
- ← AI-generated code: "Several times during the project, I lost my mental model of the codebase"
- ← Google Workspace CLI: "I built a CLI for Google Workspace — agents first."
