# AI-generated code
Type: concept
Sources: https://www.latent.space/p/reviews-dead

Code produced by AI systems, described as often requiring significant review effort.

## Relations
- → Code Review: "developers keep saying that reviewing AI-generated code requires more effort than reviewing code written by their colleagues."
- → Code Review: "the defenses we relied on (code review, testing, manual inspection) are the same ones that missed Heartbleed for two years"
- ← Ephemeral Software: "ChatGPT writes tens or hundreds of lines of Python to resize images, create a PDF, or extract data from a CSV —and then throws it away, without anyone even having seen the code"
- ← Fast-vs-Smart Model Tradeoff: "With 3x faster responses, I could add an extra cycle: 'critique the plan and address the critiques.' In the time the hare was still thinking, the tortoise ran another lap"
- ← Formal Verification: "AI is changing the scale and speed of software production faster than our ability to verify it"
