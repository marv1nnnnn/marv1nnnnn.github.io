# Procedural expressibility
Type: concept
Sources: https://sunilpai.dev/posts/after-wimp/

The emerging ability of non-programmers to describe procedures via natural language that LLMs can compile into runnable code, weakening the decades-old divide between programmers and interface consumers

## Relations
- → Capability-scoped sandbox: "if models can write code on behalf of users, where does that code run? ... THAT requires a different kind of runtime primitive"
- ← WIMP model: "the successor to WIMP is probably not "chat," at least not in the simplistic sense people sometimes mean... fixed graphical interfaces stop being the only sensible contract between user and machine once the user can increasingly express procedures through a model"
