# User-specific software
Type: concept
Sources: https://sunilpai.dev/posts/after-wimp/

Persistent per-user runtime logic attached to accounts/sessions that assembles interfaces, adapts behavior, and synthesizes application code at runtime—going beyond personalization to give each user a somewhat different program

## Relations
- ← Capability-scoped sandbox: "once users have access to systems that can generate code on their behalf, the next important question is not just how smart the model is. it is whether our software platforms are prepared to host user-specific code safely, quickly, and with tight control"
- ← Model inhabiting state: "the intelligence was not in scaffolding a fresh app. it was in understanding an existing stateful environment and using code as the mechanism of interaction with it"
- ← WIMP model: "not the end of interfaces, but the end of the assumption that interfaces must be fully fixed in advance because users cannot program the machine"
