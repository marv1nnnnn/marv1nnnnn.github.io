# Spec-driven development
Type: concept
Sources: https://www.latent.space/p/reviews-dead, https://leodemoura.github.io/blog/2026/02/28/when-ai-writes-the-worlds-software.html

Engineering discipline where precise specifications define what software must do, becoming core as AI takes over implementation

## Relations
- → Specification: "In this new paradigm, **Specs become the source of truth**."
- → Acceptance Criteria: "Humans should review specs, plans, constraints, and acceptance criteria—not 500-line diffs."
- → Ephemeral Software: "it also feels like you can specify what software is supposed to do without being 100% precise and, as long as the person (thing) implementing it and you have some shared understanding about what's left out of the spec, things will be fine"
- ← Formal Verification: "As AI takes over implementation, specification becomes the core engineering discipline"
