# Agentic Workload
Type: concept
Sources: https://opencomputer.dev/blog/where-should-the-agent-live

A class of software workloads fundamentally different from traditional applications, requiring isolated execution, broad tool access, persistent working state, and tight coupling between reasoning and execution to avoid latency from repeated tool calls.

## Relations
- → Sandbox Lifecycle Patterns: "Beyond securing the isolated environment and deciding where to place the agent, there is still the question of how that environment should live over time"
- ← Agent Placement: "agent placement is a performance decision as much as a security one"
- ← Agent Sandbox Isolation: "Agents introduce a new set of deployment needs and constraints"
