# Model inhabiting state
Type: concept
Sources: https://sunilpai.dev/posts/after-wimp/

Pattern where instead of generating a new application, an LLM analyzes an existing stateful environment and uses code as the mechanism of interaction—reading and mutating state rather than scaffolding fresh programs

## Relations
- → User-specific software: "the intelligence was not in scaffolding a fresh app. it was in understanding an existing stateful environment and using code as the mechanism of interaction with it"
- ← Code Mode: "the model stops trying to generate the program and starts inhabiting the state machine"
